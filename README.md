# Saarathi.AI

Assistive device for visually impaired individual.


## Installation
```bash
  git clone https://github.com/alt0kernel/Saarathi.AI
  cd Saarathi.AI
  create a python venv(ifykyk) -- Optional
  pip install -r requirements.txt
  Run Python scripts/voice_sim.py(voice input) (or) python scripts/sim.py(no voice input)
```
